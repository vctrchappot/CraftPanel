## Shared brand and website

The panel, website and docs share their fonts and semantic tokens. The panel uses compact Lucide controls and neutral interaction colours; the website adds pixel icons, isometric illustrations and larger display typography. Detailed website and asset rules remain in the [contributor design notes](https://github.com/vctrchappot/CraftPanel/blob/main/docs/design/README.md).
