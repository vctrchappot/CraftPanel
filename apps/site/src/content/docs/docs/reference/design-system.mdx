The dashboard, this website and these docs share one set of design tokens and one type family, [Geist](https://vercel.com/font) by Vercel. The swatches on this page follow the theme switch in the header.

<Aside>
  For contributors: the tokens live in `packages/ui/src/styles/tokens.css`. How to change them is described in [`docs/design/README.md`](https://github.com/vctrchappot/CraftPanel/blob/main/docs/design/README.md).
</Aside>

## Principles

- **Hardware workshop, not cloud console.** Warm greys, block textures on the website, real terminal output. Nothing glows.
- **Calm dashboard, clear brand.** Inside the dashboard, colour means state or interaction. Signal green, the prompt in the logo, is the brand and appears only in a few brand moments.
- **Self-hosted all the way down.** Fonts come from the official `geist` package and ship with CraftPanel. The dashboard never makes a third-party request.

## The mark

An isometric block with a console prompt: the server on your own hardware and the console you run it from.

The mark keeps its own colours. Only the top face adapts: lighter on dark surfaces, a shade darker on light ones. The wordmark next to it is Geist Sans at 600.

## Type

Three Geist families, each with one job. Weights stay low, nothing above 600: precision comes from size and spacing, not from weight.

### Contrast

Every text colour meets WCAG AA (4.5:1) on the background and on surfaces, in both themes.

| Token | Light (on bg / surface) | Dark (on bg / surface) |
| --- | --- | --- |
| `fg` | 15.3 / 16.5 | 14.8 / 13.1 |
| `fg-muted` | 6.1 / 6.5 | 7.1 / 6.3 |
| `brand-text` | 5.7 / 6.2 | 9.5 / 8.4 |
| `accent` | 5.3 / 5.7 | 9.2 / 8.2 |
| `success` | 5.3 / 5.7 | 8.2 / 7.2 |
| `warning` | 5.2 / 5.6 | 7.1 / 6.3 |
| `danger` | 5.3 / 5.7 | 5.4 / 4.8 |

Filled buttons: brand 7.6 (light) / 7.3 (dark), gold 5.9 / 9.2.

## Shape

Corners stay small, like blocks.

<div class="ds-radii">
  <div style="border-radius: var(--cp-radius-sm)"><b>2 px</b><small>badges, small parts</small></div>
  <div style="border-radius: var(--cp-radius)"><b>4 px</b><small>buttons, inputs</small></div>
  <div style="border-radius: var(--cp-radius-lg)"><b>6 px</b><small>cards, panels, dialogs</small></div>
</div>

- Spacing follows a 4 px grid.
- The dashboard is flat: borders instead of shadows, sections with dividers instead of nested cards. Only overlays (menus, dialogs) cast a shadow.
- The website may use hard offset shadows, block textures and isometric pixel scenes.

## Motion

Short and purposeful: state changes, typing terminals and demos on the website. Everything respects `prefers-reduced-motion`; with it, demos show their end state.
